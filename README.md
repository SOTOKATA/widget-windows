# Todos Widget

Todos Widget - небольшое desktop-приложение для Windows: список задач располагается в виджете поверх рабочего стола.
Задачи можно отмечать выполненными, задавать им приоритет и срок, добавлять Markdown-описания и скрывать секретные заметки. Виджет поддерживает закрепление задач, изменение размера и оформление, а приложение - запуск вместе с системой и работу из системного трея.
